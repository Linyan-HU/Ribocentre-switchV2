# Ribocentre-switch V2 visual update

The first V2 revision applies FoldBridge's responsive header, capsule navigation, gradient surfaces, rounded panels, typography and spacing while preserving Ribocentre-switch's original green (`#005826`). Scientific text, figures, sequences, structures, reference records, downloads and existing links are preserved.

Build locally with `bundle install` followed by `bundle exec jekyll serve`. The source retains the original domain name and links; publishing from this V2 repository will not update the original production site automatically.
